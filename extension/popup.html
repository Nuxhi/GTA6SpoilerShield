    Apparence de la popup

    Les contenus de ces comptes ne sont pas bloqués. Le blocage s'applique d'abord à tout ; un compte n'est débloqué que s'il est identifié avec certitude (lien de profil, jamais le nom affiché). Dans le doute, le contenu reste bloqué. Valable dans les deux modes.
